# 沙箱启停开销估算（基于 arXiv:2605.26297v2）

> 假设参数：ρ = 0.4（40% 的调用发生在沙箱已暂停、需要恢复的情况）。启动耗时取两档对比：`t0 = 100 ms`（Δt = 40 ms）与 `t0 = 450 ms`（Δt = 180 ms）。

## 1. 数据来源、计算逻辑与公式

### 1.1 数据来源

| 数据 | 论文位置 | 用途 |
|---|---|---|
| 单次工具调用耗时 μ、调用次数 n、四分位 | §VI, TABLE III（PDF v2 第 11 页） | 表 2 全部数据；表 3 的 μ̄ 主项 |
| 工具耗时 / LLM 耗时占比 s | §V, Fig. 7（矢量图几何提取，非目测） | 表 3 的 s |
| 工具调用构成 f | §VI, Fig. 10（矢量图几何提取，非目测） | 表 2 加权、表 3 的 μ̄ 加权 |
| 每任务轮数（12–62） | §IV, Fig. 3 | 交叉校验 |

TABLE III 的耗时是 **agent 观测到的单次工具执行时长**（不含沙箱创建/启动）。论文只测了 ADE、GAIA、SWE-bench Pro 三个 benchmark 的分工具耗时；DABStep 与 Terminal Bench 无分工具数据，故表 2/表 3 只覆盖这 3 个 benchmark × 4 种配置（Gemma-T / Gemma-I / Qwen-T / Qwen-I）。

### 1.2 参数假设（外部给定，论文未测）

- `ρ = 0.4`：40% 的调用需要从暂停状态恢复；
- `t0 = 100 ms`：一次启动/恢复耗时；
- 每次调用摊到的启停成本 `Δt = ρ·t0 = 40 ms`（仅 ρ 比例的调用付满 100 ms）；
- 对比口径 `t0 = 450 ms`：`Δt = ρ·t0 = 180 ms`，其余假设不变；结论中对两档并列给出；
- 串行可加：启停耗时计入墙钟，LLM 推理时间不变；不考虑在 LLM 生成期间预恢复来掩盖启动。

### 1.3 公式

```text
逐工具比值：   R(tool) = Δt / μ            = ρ·t0 / μ
按调用加权：   μ̄_w      = Σ n·μ / Σ n              （n = 该格调用次数）
不分工具均值： μ̄        = Σ_tool  f(tool) · μ(tool)   （f = Fig.10 的调用占比）
工具耗时增幅： r_tool   = Δt / μ̄
工具耗时占比： s        = T_tool / T_e2e              （Fig.7 实测）
引入启停后：   s′       = (T_tool + Δ) / (T_e2e + Δ)
                       = s·(1 + r_tool) / (1 + s·r_tool)
端到端增幅：   r_end    = s · r_tool
```

μ 取 TABLE III 的算术平均；未测量工具按默认值补（Read 0.03 s、Glob 0.02 s、Edit 0.07 s、Write 0.08 s、Grep 0.08 s、TodoWrite 0.10 s），Agent / TaskOutput / WebFetch / TaskStop 取同 benchmark 其它配置的实测值。

## 4. 解读与局限

- 启停 40 ms 与快工具（Write/Edit/Grep，0.07–0.10 s）同量级，与之比值 40%–57%；与慢工具（Bash 10–16 s、WebFetch 30 s、Agent 60–900 s）差 2–4 个数量级。
- 100 ms 档：ADE 的 r_tool 为 3.3%–6.6%，SWE-bench Pro 0.7%–1.4%，GAIA 0.2%–2.3%；折算到端到端，`s′` 的绝对变化都在 0.6pp 以内。
- 450 ms 档（Δt=180 ms，整体 ×4.5）：ADE 的 r_tool 升到 14.8%–29.8%（端到端 +1.7–2.6pp），SWE-bench Pro 3.2%–6.2%（+0.3–0.6pp），GAIA 1.0%–10.4%（+0.2–0.7pp）；加权比值从 0.41% 升到 1.84%（1:245 → 1:54）。
- 结论：启动时延要到数百毫秒量级、且负载以快工具为主（ADE 型）时，才会成为成本决策因素；在 100 ms 档它基本不影响端到端。
- 局限：`ρ`、`t0`、启停对称性均为外部假设，论文与 DSec（2609.22978）都没有启停时延实测值；表 2 的加权平均只覆盖 top-3 工具，表 3 的 μ̄ 中未测量工具按默认值补齐；论文的实验为每任务一个常驻沙箱，暂停-恢复属外推场景。

## 5. 复现说明

- Fig. 7 与 Fig. 10 的数值由 arXiv HTML 内嵌 SVG 的矢量几何解析得到：Fig. 7 取每个 bar 中 tool 段（`#d8b365`）高度占 0–100% 轴高度的比例；Fig. 10 按段色（图例 13 色对应 13 个工具）计算每格的调用占比。
- TABLE III 的 36 个格子直接取自论文表格单元格（工具名、n、μ），未做二次加工。
- 加权平均：`Σn = 20,988`、`Σn·μ = 205,648 s` → `μ̄_w = 9.80 s`。
- t0=450 ms 档只把 `Δt` 从 40 ms 换成 180 ms，其余数据不变；逐工具比值 ×4.5，`r_tool` ×4.5，`s′` 按 `s·(1+r)/(1+s·r)` 重算（非线性）。
- 源文件：`arxiv.org/html/2605.26297v2`（v2, 2026-09-21），TABLE III 位于 PDF v2 第 11 页。
