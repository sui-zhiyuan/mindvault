## 问题引入：8 位二进制环

> 能否构造一个 8 位二进制数环，使得从任意位置开始的连续 3 位数字都互不相同？

可以。这正是经典的 **de Bruijn 序列** B(2,3) 问题——长度为 8 的循环二进制串，恰好 8 个 3 位窗口，而 3 位二进制串一共也只有 2³ = 8 种，所以要求它们全部互不相同，等价于要求它们构成 8 种 3 位串的一个排列（每个恰好出现一次）。

**一个可行解：`00010111`**

把 8 个位置编号 0–7，按环形取连续 3 位：

| 起点 i | 窗口 (i, i+1, i+2) |
|---|---|
| 0 | 000 |
| 1 | 001 |
| 2 | 010 |
| 3 | 101 |
| 4 | 011 |
| 5 | 111 |
| 6 | 110 |
| 7 | 100 |

8 个窗口分别是 `000, 001, 010, 011, 100, 101, 110, 111`——正好是全部 8 种 3 位二进制串，互不重复。

（其中位置 6、7 的窗口 `110`、`100` 跨过了环的结尾回绕到开头，这正是"环"的关键。）

---

## 定义

**de Bruijn 序列** B(k, n) 是一个**循环序列**（首尾相接成环），其元素取自大小为 k 的字母表，使得长度为 n 的每一个可能的串，**恰好出现一次**作为连续窗口。

换句话说：在一个环上滑动一个长为 n 的窗口，把所有 kⁿ 种可能的 n 长串都精确地扫过一遍。

- **长度**：序列的长度恰为 kⁿ（因为每个 n 长串出现一次，每个窗口起点贡献一个符号）。
- 上面的例子就是 k=2、n=3 的情况：2³ = 8 位，覆盖 8 种 3 位二进制串。

---

## 为什么长度正好是 kⁿ

环上有 kⁿ 个起点位置，每个起点对应一个 n 长窗口，而 n 长窗口的总数也是 kⁿ 种。所以要求"互不相同"就必然"每种恰好一次"——这就是 de Bruijn 序列的最优紧凑性：**用最少（kⁿ）个符号，编码了所有 n 长组合**。

## 构造方法

### 1. 欧拉回路法（最直观）

建一个有向图（de Bruijn 图）：

- **顶点**：所有长度为 n−1 的串（共 k^(n−1) 个）。
- **有向边**：从顶点 `a₁a₂…a_{n−1}` 连向顶点 `a₂…a_{n−1}aₙ`，边上的标签就是新增的符号 `aₙ`（或者说，一条边代表一个 n 长串 `a₁…aₙ`）。

在这个图中走一条**欧拉回路**（每条边恰好经过一次），按顺序读边上的标签，就得到一个 de Bruijn 序列。

> 为什么可行：de Bruijn 图每个顶点的入度 = 出度 = k，所以欧拉回路一定存在。

### 2. "prefer-one" 贪心法（算法上常用）

从 n 个 0 开始，每一步尝试在末尾加 1，若由此产生的新 n 长窗口之前没出现过就保留，否则退回尝试加 0，如此贪心生成。

### 3. 例子：B(2, 3)

以 `00010111` 为例，de Bruijn 图顶点是 2 长串 `00, 01, 10, 11`：

```
00 ──0──> 00 ──1──> 01 ──0──> 10 ──1──> 01
                         │               │
                         1               1
                         ▼               ▼
                        11 ──1──> 11 ──0──> 10
```

沿一条覆盖所有 8 条边的欧拉回路读取边标签，即可得到 `00010111`（或 `00011101`）。

## 数量有多少

**B(k, n) 的不同序列个数**（模旋转后视为同一，按环计）由著名的公式给出：

$$ \frac{(k!)^{k^{n-1}}}{k^n} $$

- 对**二进制** B(2, n) 简化为 $2^{2^{n-1} - n}$。
- n=1：2^(2⁰−1) = 1 个（`01`）。
- n=2：2^(2¹−2) = 1 个（`0011`）。
- n=3：2^(2²−3) = 2 个（`00010111` 和 `00011101`）。
- n=4：2^(2³−4) = 16 个。

数量增长极快，这也是它有趣之处。

## 命名与历史

以**荷兰数学家尼古拉斯·霍弗特·德布鲁因（Nicolaas Govert de Bruijn, 1918–2012）**的名字命名。荷兰语发音大致是 "deh BROYN"（英语化后常读 "deh BRINE"）。

1946 年，de Bruijn 在荷兰皇家科学院院刊发表论文 **"A combinatorial problem"**，给出了**一般字母表大小 k** 下 de Bruijn 序列的计数公式。在此之前，人们只在二进制（k=2）情形下知道结果；de Bruijn 把结论推广到任意 k，这个通用结果让他的名字与该结构绑定在一起。

> 1951 年，他与 **Tanja van Aardenne-Ehrenfest** 合著 *"Circuits and trees in oriented linear graphs"*，系统化了欧拉回路、de Bruijn 图等概念。此二人还与 C.A.B. Smith 和 W.T. Tutte 一起贡献了计数欧拉回路的 **BEST 定理**（取四人姓氏首字母）。

### 但发明者其实另有其人

这是 **Stigler 定律（Stigler's law of eponymy）**的典型例子——"没有任何科学发现是以其最初发现者命名的"。

真正的先行者是法国数学家 **Camille Flye Sainte-Marie**，他在 **1894 年**就解决了二进制情形，证明了二进制 de Bruijn 序列的个数为 $2^{2^{n-1} - n}$。也就是说，de Bruijn 比最初发现晚了半个多世纪。

名字落在 de Bruijn 头上的可能原因：

1. **结论更一般**：Flye Sainte-Marie 只处理了 k=2，de Bruijn 给出了任意 k 的统一公式。
2. **论文传播面广、术语约定俗成**："de Bruijn graph" 成为组合数学与图论的标准词汇，序列名随之固定。
3. **学科交叉放大**：20 世纪后期生物信息学兴起，de Bruijn 图成为 DNA 序列组装的核心数据结构，进一步放大了该词的使用。

### 顺带一提

de Bruijn 是位多产数学家，除这条序列外，还以 **de Bruijn–Erdős 定理**（图论）、**de Bruijn 指数**（λ 演算中的变量表示法）、**BEST 定理**（计数欧拉回路）闻名。

## 类似"专一"的算法

"类似 de Bruijn"指这类算法有共同特征：**结构精巧、证明漂亮、用途高度聚焦在某一个场景里，换个场景就基本用不上**。

### 同为"比特序列构造"的兄弟

| 算法 | 内容 | 专一场景 |
|---|---|---|
| **格雷码（Gray Code）** | 相邻编码只差一个比特 | 旋转编码器、卡诺图、遗传算法变异、防竞争冒险电路 |
| **戈隆尺（Golomb Ruler）** | 刻度间两两距离互不相同且尺长最短 | 射电望远镜天线摆放、传感器稀疏布点 |

### "单点破局"的字符串/序列算法

| 算法 | 内容 | 专一场景 |
|---|---|---|
| **Manacher 算法** | O(n) 求最长回文子串 | 只干"回文"这一件事 |
| **Rabin-Karp 滚动哈希** | O(1) 滑动更新哈希匹配子串 | 字符串匹配、查重、基因组序列分析 |
| **Levenshtein 自动机** | 把"编辑距离 ≤ k"编译成自动机 | 拼写纠错、模糊搜索 |

### 概率/空间压缩"速写"家族

这类和 de Bruijn 的共性在于：**用一个很小的结构，编码原本很大的信息**。

| 算法 | 内容 | 专一场景 |
|---|---|---|
| **布隆过滤器（Bloom Filter）** | 用哈希位回答"元素是否可能存在" | 缓存穿透防护、爬虫去重 |
| **HyperLogLog** | 极少内存估算"不同元素个数" | UV 统计、大表 distinct count |
| **SimHash** | 文档压成固定长指纹，海明距离≈相似度 | 近重复文档检测 |
| **蓄水池抽样** | 从未知长度流里均匀随机抽 k 个 | 流式均匀采样 |

**共性**：问题定义极其狭窄，但在那个狭窄点上做到理论最优（时间/空间/精度的极限），因此一旦遇到对口的工业场景就不可替代。

## 常见应用

1. **门锁 / 密码破译**：de Bruijn 序列给出"最短按键串"——按这串键就能以连续 n 个键的方式试遍所有 n 位密码，无需重复输入。
2. **定位 / 编码器**：旋转编码器用 de Bruijn 环，通过读连续几个黑白图案即可唯一确定角度位置。
3. **DNA 测序（基因组组装）**：把 reads 当作 k-mer，求欧拉回路来拼装，de Bruijn graph 是核心数据结构。
4. **随机数 / 位掩码 / 组合数学**：图论与组合设计的交叉问题。
5. **数学谜题**：如"找到最短的 0/1 串，其连续 4 位覆盖所有 16 种情况"。

---

## 一句话总结

> de Bruijn 序列是"**用最短的循环串，把长度为 n 的所有 k 进制串各含一次**"的最优结构，本质上等价于在 de Bruijn 图上找一条欧拉回路。
