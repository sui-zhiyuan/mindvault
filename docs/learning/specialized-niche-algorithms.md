# 类似 de Bruijn 序列的"专一"算法

> "类似 de Bruijn"意味着这类算法有共同特征：**结构精巧、证明漂亮、用途高度聚焦在某一个场景里，换个场景就基本用不上**。

## 最像的：同为"比特序列构造"的兄弟

### 1. 格雷码（Gray Code）

- 相邻两个编码只差一个比特；循环格雷码首尾也只差一位。
- **专一场景**：旋转编码器、卡诺图化简、遗传算法中的变异、防竞争冒险的数字电路。
- 和 de Bruijn 的关系极近——两者都出自"如何精巧地排列比特"这类问题，且**同样被用在物理旋转编码器**上。

### 2. 戈隆尺（Golomb Ruler）

- 一根尺子，刻度间两两距离互不相同，且尺长最短。
- **专一场景**：射电望远镜阵列的天线摆放（避免基线重复）、传感器稀疏布点。
- 同样是把"互不相同"这个约束做到极致的组合结构。

## "单点破局"的字符串 / 序列算法

### 3. Manacher 算法

- O(n) 求最长回文子串。
- **专一场景**：就干"回文"这一件事，但干到线性时间，别处基本用不到。

### 4. Rabin-Karp 滚动哈希（Rolling Hash）

- 用 O(1) 滑动更新哈希来匹配子串。
- **专一场景**：字符串匹配、查重、最长公共子串；和 de Bruijn 一样在**基因组序列分析**里是常客。

### 5. Levenshtein 自动机

- 把"编辑距离 ≤ k"编译成一个确定性自动机，模糊匹配。
- **专一场景**：拼写纠错、模糊搜索（如搜索引擎的 "did you mean"）。

## 概率 / 空间压缩"速写"家族

这类和 de Bruijn 的共性在于：**用一个很小的结构，编码原本很大的信息**。

### 6. 布隆过滤器（Bloom Filter）

- 用几个哈希位，回答"元素是否可能存在"（允许假阳性、绝无假阴性）。
- **专一场景**：缓存穿透防护、数据库查询优化、爬虫去重。空间换精确度，只干"集合成员判定"一件事。

### 7. HyperLogLog

- 用极少量内存估算"不同元素个数"（基数）。
- **专一场景**：去重计数（UV 统计、大表 distinct count）。只干"数有多少个不同值"。

### 8. SimHash

- 把文档压成固定长指纹，海明距离小 ≈ 内容相似。
- **专一场景**：近重复网页 / 文档检测（Google 曾用于爬虫去重）。

### 9. 蓄水池抽样（Reservoir Sampling）

- 从一个长度未知的流里均匀随机抽 k 个。
- **专一场景**：流式均匀采样，只能顺序读一遍、无法回头的场景。

## 为什么它们"专一"却重要

这类算法都有一个共同点：**问题定义极其狭窄，但在那个狭窄点上做到理论最优**（时间 / 空间 / 精度的极限），因此一旦遇到对口的工业场景就不可替代。

de Bruijn 序列的"对口场景"是密码锁和编码器，格雷码是编码器，戈隆尺是射电望远镜——都是"一生只做一件事，但做到极致"的典型。
