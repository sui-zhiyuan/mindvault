## 输入 1


"【标题】
Daft 适配鲲鹏亲和多模态算子库

【背景】
鲲鹏多模态算子库以独立仓库模式交付，该库面向鲲鹏平台对图像、视频、音频等多模态处理算子做了亲和实现。Daft 侧当前的多模态处理主要依赖通用 Python 生态库，缺少与鲲鹏亲和多模态算子库的对接通道，

【描述】
在 Daft 侧完成鲲鹏亲和多模态算子库的集成适配：以独立仓库模式引入该算子库，在 Daft 的算子层（含 UDF 执行路径）封装可被物理计划调用的接口，并保证接口不可用时回退到原有实现；目标是在视频 / 文本 / 图像 / 音频 / PDF / 智能驾驶 / LLM预处理 产线中把通用实现替换为鲲鹏亲和实现，降低多模态算子的处理耗时。

【输入】
鲲鹏多模态算子库（独立仓库交付件）、Daft 0.7.2 源码、950 / 9755 标准性能验收环境中各个产线性能用例。

【输出】
1、Daft 侧集成适配源码（合入 GitCode / 蓝区代码仓）
2、集成后多模态产线可利用新增算子库"


## 输入 2


"【标题】
Daft 适配 Lance 算子下推

【背景】
Lance 作为 AI 原生列式湖存储，具备在数据源侧实现视频解码与抽帧的能力。当前视频解码、抽帧等步骤在 Daft 侧（或 Python UDF 中）执行，视频数据需要从存储层搬到计算层再做解码，存在大量跨边界数据搬运与格式转换开销。

【描述】
Lance 实现数据源侧的视频解码和抽帧能力，Daft 侧完成适配，将算子下推到 Daft 中，
使解码与抽帧尽可能贴近数据源执行，减少数据搬运与中间物化，从而降低视频产线的 I/O 与转换开销。

【输入】
Lance 侧算子下推能力（独立交付件）、Daft 0.7.2 源码、950 / 9755 标准性能验收环境、视频产线性能用例与视频数据集（InternVid）。

【输出】
1、Lance 侧能力与 Daft 侧适配源码（合入 GitCode / 蓝区代码仓）
2、算子下推前后视频产线的吞吐量与 I/O 开销对比结果"
