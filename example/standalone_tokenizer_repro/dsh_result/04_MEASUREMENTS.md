# 实测数字汇总

> 口径：`tokenizer_ms` p50；ARM 为 10 block 配对（每进程 3 轮 ×（10 预热+30 正式）=90 次正式调用）；x86 为交错配对。**负 = 更快**。CI 为 95% bootstrap（种子 20260924）。

## 一、aarch64（.50）：全部变体 vs 基线 neon8

| 变体 | 关键编译/源码差异 | default | rayon1 | rayon8 |
|---|---|---|---|---|
| **opt（P1 补丁）** | `HashMap`→`Vec<u32>` | **−23.65%** [−24.38,−22.93] | **−24.14%** [−24.81,−23.51] | **−23.68%** [−24.59,−22.73] |
| v1-native | `-Ctarget-cpu=native` | −0.59% [−1.44,+0.30] | −1.11% [−1.84,−0.41] | −0.75% [−1.41,−0.13] |
| v2-feat | v1 + 补齐 13 个 feature | −1.24% [−2.21,−0.29] | −1.10% [−2.01,−0.22] | −0.83% [−1.61,−0.08] |
| v3-featvl | v2 + `-Cllvm-args=-aarch64-sve-vector-bits-min=256` | −1.25% [−1.97,−0.57] | −1.05% [−2.08,−0.06] | −0.39% [−1.23,+0.53] |
| **v4-lto（P2）** | v2 + `lto="fat"`+`codegen-units=1` | **−10.50%** [−11.07,−9.97] | **−10.23%** [−10.83,−9.59] | **−10.32%** [−11.06,−9.64] |
| opt-feat | P1 + v2 参数 | −24.40% [−25.00,−23.79] | −23.09% [−23.76,−22.43] | −24.07% [−24.72,−23.31] |
| **opt-lto（P4 最优）** | **P1 + v2 参数 + LTO/CGU=1** | **−30.11%** [−30.65,−29.54] | **−29.53%** [−30.55,−28.65] | **−29.68%** [−30.58,−28.87] |

绝对耗时：基线 neon8 = 37.17/37.28/37.25 ms → opt-lto = **26.08/26.42/26.30 ms**；opt-lto 逐 block 比值 0.688~0.714（10/10 全胜）。

**A/A 噪声底（.50）**：−0.28% [−0.74,−0.02]、−0.24% [−2.20,+1.02]、−0.00% [−1.76,+2.84] → 噪声约 ±1~2%，上面 P1/P2/P4 的幅度远高于它。
