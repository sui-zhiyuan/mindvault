腾讯场景介绍：CubeSandbox

CubeSandbox 是腾讯云开源的 AI 智能体沙箱服务，为智能体提供安全、快速、低成本的代码执行与浏览器自动化环境，支持单机或集群部署。它主要解决四类问题：

1. 不可信代码的安全隔离：智能体会执行模型生成的代码，普通容器存在逃逸风险。CubeSandbox 为每个沙箱分配独立的微虚拟机内核，实现硬件级隔离，从根本上阻断容器逃逸和对宿主机的攻击。
2. 启动慢拖累交互：智能体任务短而频繁，等待环境就绪会直接影响体验。CubeSandbox 通过内存快照克隆跳过内核启动，冷启动低于 60ms，并支持毫秒级检查点、回滚与分叉探索。
3. 高并发下的资源成本：写时复制共享内存页，使单个沙箱的额外内存开销低于 5MB，单节点可驻留上千个实例，空闲时自动休眠、按需唤醒。
4. 迁移与扩展门槛：兼容 E2B SDK，改一个环境变量即可从 E2B 云迁移；可从单机平滑扩展为多节点集群，并内置 eBPF 网络隔离与凭据代理。

典型用法包括代码执行、浏览器自动化以及强化学习训练环境。


字节场景介绍：LAS（AI 数据湖服务）与 Daft

LAS 是火山引擎面向大模型的 AI 数据湖服务，Daft 是其主力数据处理引擎，以 Python 接口处理文本、图像、音视频等多模态数据，并由 Rust 内核提供向量化执行与异步 IO。它主要解决四类问题：

1. 多模态数据分散难管：文本、图像、音视频格式各异、来源分散。LAS 将其统一入湖存储，并深度优化新一代湖格式 Lance 与 Iceberg，Daft 可将 Parquet、图像、音视频等数据直接转换为 Lance。
2. 多模态处理要反复开发：清洗、标注、特征提取等环节过去常需各团队自建。LAS 内置数百个多模态数据处理算子，用户通过 Daft 直接调用、组合成处理流水线。
3. 大规模处理的算力调度：数据量大且同时需要 CPU 与 GPU。LAS 深度优化 Ray、PySpark 分布式引擎，支持 CPU、GPU 异构资源混合调度。
4. 数据到模型链路割裂：Daft 可直接读取 LAS 数据集、按列增量合并到 Lance 表，处理结果可无缝对接火山方舟，缩短从原始数据到模型训练的路径。
